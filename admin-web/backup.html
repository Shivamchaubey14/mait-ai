A cold copy of the whole database, as a ZIP you can keep or restore from.

This archive contains personal data.

Members' Aadhaar, mobile numbers and bank details are inside it. Taking the backup is logged against your account in the audit trail. Keep the file somewhere only the office can reach.

Download a backup

Everything the portal holds — accounts and roles, the Mait and MPP masters, members and non-members, AI events, inventory, indents, rates, payments and the audit trail — is serialized to JSON and zipped, with a manifest and restore notes beside it. The archive is built on the server before the download begins, so there is a pause on a large database before the first byte arrives.

  • data/maitai-data.json Every table, as a Django fixture.
  • manifest.json When it was taken, by whom, and row counts.
  • RESTORE.txt The steps to load it into a fresh database.
